# RELISTO

Vístete rápido. Dale más vida a tu ropa.

App web instalable (PWA): abre `index.html` desde GitHub Pages y agrégala a la pantalla de inicio.
Tus prendas, historial y fotos se guardan **solo en tu teléfono** (IndexedDB); este repositorio
contiene únicamente el código de la app y datos de demostración ficticios.
